# Bhakti Restaurant Webpage

A clean, responsive, and minimal webpage for **Bhakti Restaurant**, a 100% pure vegetarian family dining restaurant.

## Features
- **Responsive Layout**: Adapts smoothly to mobile and desktop displays.
- **Minimal CSS**: Fast loading, simple, and clean styling.
- **Images Included**:
  - `rest2.jpg`: Full background.
  - `rest1.jpg`: Featured under Chef's Special.
  - `rest3.jpg`: Featured under Dining Area.
- **Error Handling**: Custom `404.html` page for handling missing resource errors in cloud hosting environments.
